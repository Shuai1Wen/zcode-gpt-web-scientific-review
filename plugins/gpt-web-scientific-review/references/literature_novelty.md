# Literature and Novelty Review Profile

Novelty should be expressed as an occupied-space analysis, not a slogan.

Build a nearest-neighbor matrix:

| Work | Same task? | Same data regime? | Same operator? | Same generalization claim? | Same validation? | Remaining gap |
|---|---|---|---|---|---|---|

Require the reviewer to identify:

1. nearest task paper;
2. nearest mathematical/operator paper;
3. nearest dataset/regime paper;
4. nearest evaluation protocol;
5. what is already occupied;
6. what exact capability is still unoccupied;
7. whether the proposed algorithm actually supplies that capability.

A combination of two known components is not automatically novel if the combined capability has already been demonstrated.
